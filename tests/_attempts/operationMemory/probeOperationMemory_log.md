## 2026-08-31. 선행 연구에서 가져온 경계

- [NewsEdits](https://aclanthology.org/2022.naacl-main.10/)는 뉴스 120만 건의 460만 판을 모았고 기사 수정에는
  사실 갱신이 흔함을 보였다. 교정 제목이나 뒤 판이라는 이유만으로 뜻 보존이라고 두지 않는다.
- [ArXivEdits](https://aclanthology.org/2022.emnlp-main.641/)는 논문 751편의 문장 수정 1천 쌍을 사람이
  분류했다. 단순 문장 유사도보다 바뀐 span과 수정 의도를 분리하는 편이 설명 가능하다.
- [ParaRev](https://aclanthology.org/2025.wraicogs-1.4/)는 문단 문맥과 자세한 수정 지시가 문장 단독
  수정 지시보다 낫다고 보고했다. 이 문맥은 생성 모델의 재작성 입력에 쓰되, 연산 선택 조건으로는 쓰지 않는다.
- [WikiAtomicEdits](https://aclanthology.org/D18-1028/)는 한 번에 한 연속 구간만 바뀐 위키 수정 이력을
  원자 편집으로 다룬다. 이 탐침도 일대일 문장과 한 국소 조각을 먼저 고정한다.

따라서 이 탐침의 차별점은 수정 이력 검색이 아니다. 사람이 한 고침을 실행 가능한 표면 연산으로 컴파일하고,
사실 표면 불변식과 단어 경계와 기권을 연산 선택에 함께 넣는 것이다. 문단 문맥은 생성 모델이 결과를 자연스럽게
잇는 데 쓸 수 있지만, cue 유사도나 임베딩은 어떤 고침을 실행할지 고르지 않는다.

## 2026-08-31. 고정 보류 실험

서로 다른 저장소의 수정으로 학습과 보류를 가른 긍정 네 과제와 기권 세 과제를 고정했다. 긍정은 위 표의
`렌더`, `여러가지`, `그 중`, `됩니다:`이고, 기권은 `이것은 -> 이는`, `에 의해 -> 에 따라`, 이미
`렌더링` 안에 든 `렌더`다. 모델은 `qwen3:8b`, digest
`500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`, temperature 0, seed 42,

안전 성공은 목표 승인본 일치, 보호 사실 보존, 뜻 보존, 받아들일 수 있는 문장, 새 error 0을 모두 만족한

표면 연산은 이유만에 2승 0패 5무, 무조건 본보기에 3승 0패 4무, 원문 완전 일치에 2승 0패 5무였다.

## 2026-08-31. 제품 판정

`surfaceSubstitution`만 승격한다. 승인 전후에서 32자 이하 조각 하나를 추출하고, 공백과 문장부호를 걷은
편집 거리가 1 이하일 때만 설정으로 읽는다. 지시어, 보호 원자가 든 조각, 여러 자리 일치, 단어 내부 일치,
코드와 URL과 링크 목적지 안의 일치는 기권한다. 적용 전후의 숫자, URL, 라틴 식별자, 경로, 코드, 링크
목적지의 다중집합을 다시 비교한다. 표층으로 알아낼 수 없는 한국어 고유명사와 프로젝트 용어는
`protectedTerms`로 잠근다.

확정 `Finding.fix`, 원문 완전 일치 `patch`, 표면 연산 순서로 우선한다. 현재 문장에 연산 둘이 맞아도
고르지 않는다. Python과 npm이 같은 연산 추출과 적용 계약을 가지며, 탐침도 제품 함수를 직접 호출한다.
`hanlint learn`은 정확 패치와 표면 연산을 분리해 후보로 내고 자동 승인하지 않는다. lint JSON과
`writingPacket`은 가드를 통과한 원문의 완성 `result`만 전달한다. 지시어 치환, 피동 의미 전환, 사실 갱신,
문장 재배열은 계속 원문 완전 일치 패치나 사람과 평가자의 몫이다.

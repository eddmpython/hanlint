# 블라인드 작문 아레나 자기 탐침

날짜: 2026-08-31

일곱 프리셋의 기존 사실 고정 과제를 `WritingTrial`로 바꾸고, 모든 lint 규칙을 끈 합성 글로 아레나 배선만
검사한다. 두 결과가 guard를 통과해야 블라인드 비교가 생기고, 패킷에는 전략명이 없어야 하며, 사람 평가

않는다. 일곱 종류가 같은 안전·익명화·기록 계약을 공유하는지만 확인한다.

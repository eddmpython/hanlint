# 글쓴이의 수정 이력과 자기 검증 기록 (정규식). 독자가 본 적 없는 초고를 고치는 장면이라 본문에서 뺀다.
# 출처: cinch 의 전역 blog-writing 스킬, 무엇을 빼는가의 반드시 빼는 것 첫 항목.
# 존댓말 종결만 본다. 참고 문서와 명세는 한다체로 검증 사실을 남기는 것이 제 일이라 잡지 않는다.
처음에는[^.!?]{0,25}(?:썼|적었|썼다가|적었다가|쓴 적)
(?:초고|초안|첫 판)(?:에서|에는|에|을|를)[^.!?]{0,20}(?:고쳤|바꿨|지웠|썼)
줄 알았[^.!?]{0,30}(?:확인|알고 보니|아니었)
(?:것|줄)을 확인했습니다
직접 확인해 (?:봤|보았)습니다

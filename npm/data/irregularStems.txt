# 불규칙 활용 어간. `어간<TAB>부류`. 어미 `아/어` 가 붙을 때만 모양이 바뀌고 습니다 앞에서는 규칙이다.
# 부류: ㅂ (춥+어 → 추워), ㅂ와 (돕+아 → 도와), ㄷ (듣+어 → 들어), ㅅ (낫+아 → 나아), ㅎ (그렇+어 → 그래),
# 르 (다르+아 → 달라). 규칙 활용하는 같은 받침의 어간 (잡다, 입다, 벗다, 묻다 (파묻다)) 은 적지 않는다.
#
# 출처: 본보기와 문형의 서술어와 소유 저장소 상위 어절에서 실제로 나온 것 (다르다, 빠르다, 새롭다,
# 자연스럽다, 어렵다, 쉽다, 듣다, 낫다, 그렇다). 나머지는 그 부류의 대표적인 것만 두고 말뭉치가 오면 잰다.

# 코드 한 줄이 요구하는데 설치 줄에 드러나지 않는 패키지. `정규식<TAB>패키지[extra]<TAB>왜`. 설치 줄에 없으면 installImport가 확인 권고로 짚는다.
# 실측: 블로그 004가 ibis-framework[duckdb]만 설치하고 ibis.sqlite.connect를 썼고 사람 평가자가 짚었다.
ibis\.sqlite\.connect	ibis-framework[sqlite]	ibis의 sqlite 백엔드는 extra로 따로 받는다
ibis\.duckdb\.connect	ibis-framework[duckdb]	ibis의 duckdb 백엔드는 extra로 따로 받는다
ibis\.postgres\.connect	ibis-framework[postgres]	ibis의 postgres 백엔드는 extra로 따로 받는다
dask\.dataframe	dask[dataframe]	dask의 dataframe은 extra로 따로 받는다
pd\.read_excel\(|\.to_excel\(	openpyxl	pandas의 엑셀 읽기와 쓰기에는 openpyxl이 있어야 한다
pd\.read_parquet\(|\.to_parquet\(	pyarrow	pandas로 parquet을 읽고 쓰려면 pyarrow가 있어야 한다
pl\.read_excel\(	fastexcel	polars의 엑셀 읽기는 fastexcel을 기본 엔진으로 쓴다
plt\.|import matplotlib	matplotlib	그림을 그리려면 matplotlib이 있어야 한다
requests\.get\(|requests\.post\(	requests	requests는 표준 라이브러리가 아니다
